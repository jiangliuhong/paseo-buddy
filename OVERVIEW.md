Paseo Buddy is a macOS floating companion for monitoring Paseo agents. The desktop app shows running agents in red, completed unread agents in green, and permission-blocked agents in a separate list. Each row shows the project, workspace, agent name, and available turn duration. The pill can be dragged anywhere on screen, stays out of the Dock, and opens its list when clicked. First launch starts in the bottom-right corner, and saved positions are restored later. The plugin’s settings page provides opacity and size controls that apply live and persist in Paseo.

The daemon plugin exposes a read-only agent snapshot RPC. On local macOS daemons, enabling the plugin automatically downloads the matching desktop companion from its pinned GitHub release, verifies the archive checksum and app identity/signature, and starts the floating window. Disabling the plugin closes its owned window. Downloaded binaries are cached privately in the user’s Library/Caches directory. The desktop application reads the local daemon directly and can also be run independently.

Paseo 0.11.1 or later, npm for source preparation, and a local macOS daemon running in the logged-in desktop session are required. The first companion download is about 100 MB and needs GitHub access. Remote daemons do not launch a window on the client machine. The desktop app discovers the daemon through the selected Paseo home and supports explicit loopback TCP endpoints. It reads the daemon's existing local credential in its main process, keeps it in memory, and never sends it to the renderer. Read status remains controlled by Paseo; opening Buddy does not mark agents read.

The current preview is ad-hoc signed and not Apple notarized. The plugin does not disable Gatekeeper or alter quarantine flags.
