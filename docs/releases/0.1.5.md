# Paseo Buddy v0.1.5

Buddy now aggregates running agents and completed-unread conversations from configured Paseo hosts through the desktop client's existing connections. Cards identify their host and open the owning conversation. Each host reconnects independently; disconnected hosts are shown separately and do not contribute stale agents to the count. Completion notifications use host-scoped turn identities to avoid collisions.

The pill context menu now uses screen coordinates, stays above the floating window, and preserves the pill anchor while opening and closing in collapsed or expanded mode.

## Update

Requires macOS 13+ and Paseo 0.11.2 or later. Run `paseo plugin update paseo-buddy`, disable/re-enable the plugin and restart the Paseo client. Under **Paseo Buddy → 悬浮窗口**, stop the old companion, then choose **下载并启动** to download and verify the matching native executable. Apple Silicon and Intel executables and SHA-256 manifests are attached; Xcode is not required for installation.

Open the Paseo sidebar once to mount the host monitor. Observation of known hosts continues while the sidebar is hidden; newly added/removed hosts reconcile when it mounts again. Closing the client expires remote state within 15 seconds while local daemon observation continues. Up to 64 configured hosts and 5,000 aggregate agents are supported.

Remote cards offer **Open in Paseo**; **Mark as read** remains local-only because the borrowed public API does not expose that operation. Opening a conversation follows Paseo's normal read behavior. Notifications require existing macOS authorization and are not backfilled after a disconnect.

Validation includes 107 automated tests, TypeScript checks, server/client builds and compilation of the actual Swift source with anchor geometry checks. Real multi-host GUI acceptance, actual menu-event acceptance, Intel hardware acceptance and Apple Developer signing/notarization remain unverified.
