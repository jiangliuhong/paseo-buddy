Paseo Buddy v0.1.2 adds appearance preferences inside Paseo and a bottom-right first-launch position.

- First launch defaults to the primary display’s bottom-right work-area corner. Existing saved positions still take precedence.
- Open **Settings → Plugins → Paseo Buddy → 悬浮窗口** to set opacity (30–100%) and size (75%, 100%, 125%, or 150%).
- Saving updates the managed floating window immediately. Settings persist in Paseo and restore before desktop startup.
- Popover placement, dragging, boundary clamping, and saved anchors track the selected scale.
- Invalid settings preserve a usable window and provide retry/reset controls.

### Update an existing installation

```sh
paseo plugin update paseo-buddy
```

Review and approve the proposed revision. The updated plugin automatically downloads and verifies its matching v0.1.2 desktop companion, then starts it. No manual DMG download is needed. If an old independently launched app is still running, quit that old instance once before enabling the updated plugin.

For a new installation, enable plugins yourself in Paseo Settings and install `git:jiangliuhong/paseo-buddy`, or pin the release:

```sh
paseo plugin add git:jiangliuhong/paseo-buddy --ref v0.1.2
```

### Requirements and limits

Paseo >=0.11.1, npm for Git-source preparation, and a local macOS daemon in the logged-in desktop session. The plugin runs the companion on the daemon machine, not on a remote client. The initial companion download is about 100 MB; later launches reuse the verified cache.

Apple Silicon and Intel DMG/ZIP packages remain available for standalone use. This is an ad-hoc signed preview, without Apple Developer signing or notarization. The plugin does not disable Gatekeeper or change quarantine flags. Opacity/size controls require both the v0.1.2 plugin and v0.1.2 companion.

Automatic new-version notifications are not included. Completion system notifications and conversation deep links also remain unimplemented.
