Paseo Buddy's first macOS preview release provides a compact floating monitor for local Paseo agents.

- Red running counts and green completed-unread counts, synchronized with Paseo.
- Separate permission-wait and completed-unread lists.
- Project/workspace labels, agent names, turn duration, and fast full-name previews.
- Drag anywhere on the pill, click anywhere to toggle its list, and place it at the screen bottom.
- No Dock icon and automatic reconnect with fresh daemon snapshots.

### Download and run

Download the `arm64` DMG for Apple Silicon, or the `x64` DMG for Intel Macs. Open the DMG and drag Paseo Buddy into Applications. Start Paseo 0.11.1 or later, then launch Paseo Buddy. Right-click the pill to quit. ZIP archives and SHA-256 checksums are also included.

This preview is **not signed with an Apple Developer certificate or notarized**. macOS may block its first launch. Follow Apple's instructions under Privacy & Security only if you trust this release: https://support.apple.com/102445 . The downloaded app does not require Node.js or npm.

### Optional Paseo daemon plugin

The repository also provides a read-only snapshot RPC plugin:

```sh
paseo plugin add git:jiangliuhong/paseo-buddy --ref v0.1.0
```

Enable plugins yourself in Paseo Settings if using that RPC. Installing the plugin does not launch the floating app; the desktop app works independently of the plugin.

### Known limits

Local loopback TCP daemons only. No completion system notifications, conversation navigation, plugin-driven auto-start, automatic app updates, or Apple notarization. Completed-unread counts clear when Paseo marks agents read.
