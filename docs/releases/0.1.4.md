# Paseo Buddy v0.1.4

The native AppKit companion now installs with a single **下载并启动** action under Paseo Buddy → 悬浮窗口. It downloads the exact matching GitHub Release for Apple Silicon or Intel, verifies version/source/architecture and binary SHA-256, and starts the window. Users do not need Xcode or Command Line Tools. Subsequent plugin enables reuse the verified cache without downloading.

Stop/disable cancel downloads. Missing releases, interrupted downloads and invalid assets never launch; retry is available. Old Electron copies and unknown caches are preserved.

The version-tag workflow builds both native architectures, runs validation, and publishes a GitHub Release containing two executables and two manifests. Real GitHub-download execution, Intel hardware acceptance and Apple Developer signing/notarization remain unverified.
