# Paseo Buddy v0.1.6

This release reduces synchronous work when opening and updating the floating agent list. Unchanged lists reuse their existing native views, and bursts of state updates are merged into one render after 50 ms. Explicit expand/collapse actions render immediately. The pill also accepts the first click while its window is inactive, and elapsed labels reuse preconfigured date formatters.

Large lists now show up to 30 agents per page with Previous/Next controls. Pages preserve status grouping, and the pill badges and status totals continue to count the complete snapshot. All agents remain accessible across pages; the page index is clamped when the list shrinks.

## Update

Requires macOS 13+ and Paseo 0.11.2 or later. Run `paseo plugin update paseo-buddy`, disable/re-enable the plugin and restart the Paseo client. Under **Paseo Buddy → 悬浮窗口**, stop the old companion, then choose **下载并启动** to install the matching v0.1.6 native executable. Updating the plugin alone does not update an already-running native companion. Apple Silicon and Intel executables and matching SHA-256 manifests are attached; Xcode is not required for installation.

## Validation

Validation includes 107 automated tests, TypeScript checks, server/client builds, actual Swift source compilation and native checks covering all 5,000 agents across pages, ordering, page clamping, render-state invalidation, first-mouse acceptance and timestamp compatibility. Both native architectures are cross-compiled for release.

The reported intermittent click delay has not been reproduced or measured in a real desktop session. Actual inactive-window clicks, rapid live updates and keyboard paging remain GUI acceptance items. Intel hardware execution and Apple Developer signing/notarization remain unverified.
