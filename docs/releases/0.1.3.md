Paseo Buddy v0.1.3 automatically cleans up unused older desktop companion caches after a successful startup.

- The current version must be verified and running before cleanup begins.
- Only marked older caches under `~/Library/Caches/Paseo Buddy/companions` are removed. Running older apps/helpers, newer versions, unknown directories, and incomplete downloads are retained.
- Failed downloads, failed startups, or unavailable process information leave old caches intact. Cleanup does not block the floating window.
- Paseo settings and saved window positions are preserved. Later launches reuse the current verified cache without downloading again.

### Installation and update

Update an existing installation:

```sh
paseo plugin update paseo-buddy
```

Review and approve the proposed revision in Paseo. The plugin downloads and verifies its matching v0.1.3 companion on first use, then starts it automatically. No manual DMG download is needed.

For a new installation, enable plugins in Paseo Settings and install:

```sh
paseo plugin add git:jiangliuhong/paseo-buddy --ref v0.1.3
```

Requires Paseo >=0.11.1, npm for Git-source preparation, and a local macOS daemon in the logged-in desktop session. Apple Silicon and Intel packages are available. This remains an ad-hoc signed preview without Apple Developer signing or notarization. Automatic new-version notifications are not included.
